# @todo_qa/utils

Shared reusable utility functions and custom hooks for the monorepo.

## Purpose
This package contains pure utility functions and shared custom React hooks that can be utilized across any application in the monorepo.

## When to use it
- When writing a general-purpose helper function (e.g., date formatting, mathematical utilities).
- When generating a shared hook using `pnpm generate hook [Name] --shared`.

## When NOT to use it
- Do not put feature-specific API calls or business logic here.
