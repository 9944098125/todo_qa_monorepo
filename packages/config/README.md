# @todo_qa/config

Shared configurations for the monorepo.

## Purpose
This package provides a central location for shared configuration code such as global constants, environment helper functions, theme configurations, and other shared setup.

## When to use it
- To define a constant that both `frontend` and `backend` need to share.
- When generating shared configurations using the custom generators.

## When NOT to use it
- For application-specific configuration that doesn't need to be shared.
