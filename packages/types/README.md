# @todo_qa/types

Shared TypeScript types and interfaces for the monorepo.

## Purpose
This package centralizes common data structures, API response types, and generic TypeScript interfaces used across multiple applications.

## When to use it
- When multiple apps or packages need to share the same TypeScript types (e.g., User model, generic API responses).

## When NOT to use it
- For types that are strictly specific to a single component or a single feature in one app.
